
## Bun 사용법 요약

## 설치 및 초기화

* 설치: curl -fsSL https://bun.sh | bash 명령어로 설치함.
* 버전 확인: bun --version으로 설치 확인 가능함.
* 프로젝트 시작: bun init 입력 시 package.json과 기본 파일 자동 생성됨.

------------------------------
## 패키지 관리 (npm 대체)

* 설치: bun install 실행함. 속도가 npm보다 수십 배 빠름.
* 추가: bun add [패키지명] (개발용은 -d 플래그 사용함).
* 제거: bun remove [패키지명] 사용함.
* 실행: bunx [패키지명] (npx와 동일하며 훨씬 빠름).

------------------------------
## 코드 실행 및 빌드

* 스크립트 실행: bun run [스크립트명] 또는 bun [스크립트명] 입력함.
* 파일 실행: bun index.ts 실행함. TypeScript를 별도 설정 없이 바로 실행함.
* 워치 모드: bun --watch index.ts 사용 시 파일 수정 시마다 자동 재실행됨.
* 번들링: bun build ./index.ts --outdir ./build로 빌드함.

------------------------------
## 내장 API 활용

* HTTP 서버: Bun.serve({ fetch(req) { return new Response("Hi"); } }) 형태로 서버 구동함.
* 파일 읽기: Bun.file("data.txt")로 고성능 파일 입출력 처리함.
* 환경 변수: 별도 라이브러리 없이 .env 파일을 자동으로 불러옴.


추가 팁:

* 기존 Node.js 프로젝트에서 node_modules와 lock 파일 지우고 bun install 하면 바로 전환됨.
* 테스트도 bun test 명령어로 Jest보다 빠르게 수행 가능함.
