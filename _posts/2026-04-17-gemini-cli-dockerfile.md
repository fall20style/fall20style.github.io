## 🛠️ Dockerfile 작성...

- 베이스 이미지... 노드 사용...FROM node:20-slim
- CLI 설치...RUN npm install -g @google/gemini-cli
- 실행 경로...WORKDIR /app
- 기본 명령...ENTRYPOINT ["gemini"]

------------------------------
## 🚀 빌드 및 실행...

   1. 이미지 만들기...
   * docker build -t gemini-cli .
   2. 컨테이너 돌리기...
   * API 키가 꼭 필요함...
      * docker run -it -e GEMINI_API_KEY="본인_키" gemini-cli
