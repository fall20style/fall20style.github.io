* 소스 코드: IoTivity 공식 GitHub 저장소 기준임.
* GCC 9 설정: update-alternatives로 gcc 명령어를 GCC 9에 고정함.
* 빌드 에러 해결: chrpath 미설치로 인한 Error 127 문제를 패키지 추가로 해결함.

``` Dockerfile
FROM ubuntu:20.04
# 1. 필수 패키지 설치 (GCC 9, SCons, chrpath 등)RUN apt-get update && apt-get install -y \
    git \
    build-essential \
    gcc-9 \
    g++-9 \
    scons \
    chrpath \
    && rm -rf /var/lib/apt/lists/*

# 2. 시스템 기본 gcc/g++ 별칭을 GCC 9로 연결
RUN update-alternatives --install /usr/bin/gcc gcc /usr/bin/gcc-9 100 \
    --slave /usr/bin/g++ g++ /usr/bin/g++-9
    
# 3. 소스 코드 클론 (선택 사항)
# RUN git clone https://github.com/iotivity/iotivity.git

# 4. 버전 확인 및 빌드 준비 완료
RUN gcc --version && chrpath --version
```

## 주요 조치 사항

1. 레포지토리 연결: IoTivity 빌드를 위해 https://github.com/iotivity/iotivity.git 소스를 활용함.
2. 도구 체인 고정: GCC 9을 기본 컴파일러로 지정하여 호환성 문제를 방지함.
3. 라이브러리 경로 처리: chrpath 설치를 통해 .so 파일 RPATH 수정 에러를 차단함.

이 설정으로 IoTivity 빌드 환경 구축이 완료됨.
빌드 중에 추가 라이브러리(boost, openssl 등) 의존성 에러가 발생하면 바로 말해주기 바람.
