## Python 3.15-dev 및 fastmcp 환경 구축

### 1. Pyenv 설치 및 빌드 의존성 해결
시스템 기본 파이썬에 영향을 주지 않기 위해 pyenv를 설치하고, 소스 빌드에 필요한 라이브러리를 먼저 세팅함.

* pyenv 자동 설치 스크립트 실행
```
curl https://pyenv.run | bash
```
* 파이썬 컴파일에 필요한 필수 패키지 설치
```
sudo apt update; sudo apt install build-essential zlib1g-dev libncurses5-dev \
libgdbm-dev libnss3-dev libssl-dev libreadline-dev libffi-dev wget \
libbz2-dev liblzma-dev python3-openssl -y
```

### 2. 파이썬 버전(3.15-dev) 설치
최신 개발 버전인 3.15-dev를 설치하고 시스템 전역(Global) 버전으로 지정함.

* 3.15-dev 버전 빌드 및 설치
```
pyenv install 3.15-dev
```

* 설치 경로 확인 (정상 설치 여부 체크)
```
whereis python3.15
```

* 시스템 기본 파이썬 버전을 3.15-dev로 변경
```
pyenv global 3.15-dev
```

* 설정된 버전 확인
```
python --version
```

### 3. 독립 가상환경(venv) 생성 및 활성화
프로젝트 간 패키지 충돌을 방지하기 위해 전용 가상환경을 만들고 진입.

* myenv_py3.15라는 이름의 가상환경 생성
```
python -m venv myenv_py3.15
```

* 가상환경 디렉토리로 이동
```
cd myenv_py3.15/
```
* 가상환경 활성화 (프롬프트 앞에 (myenv_py3.15) 표시됨)
```
source bin/activate
```

### 4. fastmcp 라이브러리 설치
활성화된 가상환경 내에 Model Context Protocol(MCP) 서버 구축을 위한 fastmcp를 설치함.

* pip를 통한 fastmcp 설치
```
pip install fastmcp
```
* 설치된 패키지 정보 확인
```
pip show fastmcp
```

- 이후 설치가 잘 안됨. 3.14.3으로 변경해서 다시 시도함.
