# tmux 사용하기

## WSL에서 tmux 설치
```
sudo apt-get install tmux
```




## tmux configuration

내가 사용하는 설정

```
# vi-style controls for copy mode                                                                          
                                                                                                           
unbind C-b                                                                                                 
set -g prefix C-a                                                                                          
bind C-a send-prefix                                                                                       
                                                                                                           
#set-window-option -g mode-keys vi                                                                         
                                                                                                           
set-window-option -g mode-keys vi                                                                          
bind-key -T copy-mode-vi 'v' send-keys -X begin-selection                                                  
bind-key -T copy-mode-vi 'y' send-keys -X copy-pipe-and-cancel "wl-copy"                                   
bind C-p run "wl-paste --no-newline | tmux load-buffer - ; tmux paste-buffer"                              
                                                                                                           
                                                                                                           
# split windows like vim                                                                                   
# vim's definition of a horizontal/vertical split is reversed from tmux's                                  
                                                                                                           
                                                                                                           
bind s split-window -v                                                                                     
bind v split-window -h                                                                                     
                                                                                                           
# move around panes with hjkl, as one would in vim after pressing ctrl-w                                   
bind h select-pane -L                                                                                      
bind j select-pane -D                                                                                      
bind k select-pane -U                                                                                      
bind l select-pane -R                                                                                      
                                                                                                           
# reload config                                                                                            
bind r source-file ~/.tmux.conf \; display-message "Config reloaded..."                                    
                                                                                                           
# BEGIN Powerline setting ===========================================================                      
#source /usr/local/lib/python2.7/dist-packages/powerline/bindings/tmux/powerline.conf                      
#set-option -g default-terminal "screen-256color"                                                          
# END Powerline setting =============================================================    
```

## config를 이용해서 tmux를 실행하기
```
tmux -f ~/tmux.conf
```


# tmux.conf Configuration Explanation

Your `tmux.conf` file is organized into several key functional sections, primarily focused on making tmux feel like Vim.

### Configuration Organization:

1.  **Prefix Key Mapping**
    *   **Unbinds `C-b`**: Disables the default prefix key.
    *   **Sets `C-a` as the new prefix**: Changes the prefix to `Ctrl-a`, which is more accessible and commonly used in terminal multiplexers like `screen`.

2.  **VI-style Copy Mode**
    *   **`mode-keys vi`**: Enables Vim-like keybindings for navigating and selecting text within tmux's copy mode.
    *   **Custom Keybindings**: 
        *   `v`: Starts a selection (matches Vim's visual mode).
        *   `y`: Copies the selection to the system clipboard using `wl-copy` (Wayland).
        *   `C-p`: Pastes the system clipboard content using `wl-paste`.

3.  **Vim-like Window Splitting**
    *   **`s`**: Splits the current window horizontally (top and bottom).
    *   **`v`**: Splits the current window vertically (left and right).

4.  **Vim-like Pane Navigation**
    *   **`h`, `j`, `k`, `l`**: Allows you to navigate between panes using standard Vim directional keys after pressing the prefix.

5.  **Configuration Management**
    *   **`r`**: Reloads the configuration file and displays a "Config reloaded..." message. 
    *   *Note: Your current config points to `~/.tmux.conf`, but your file is named `~/tmux.conf`.*

6.  **Powerline Placeholder**
    *   Contains commented-out lines for Powerline integration and 256-color terminal support, which can be enabled if the necessary dependencies are installed.
