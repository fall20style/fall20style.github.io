## 1. 주요 특징

* Git 연동: GitHub/GitLab 커밋 시 자동 빌드 및 배포됨.
* 속도: 클라우드플레어 에지 네트워크 써서 전 세계 어디서든 빠름.
* 무제한: 무료 플랜도 대역폭(트래픽)이랑 요청 수 무제한임.
* 풀스택: 'Functions' 기능으로 서버리스 백엔드 구성 가능함.

## 2. 장점

* 미리보기: 브랜치마다 고유 URL 생성돼서 결과물 확인 편함.
* 보안: HTTPS(SSL) 기본 적용되고 디도스 방어 기본 포함임.
* 협업: 팀원 초대 무제한이라 프로젝트 관리하기 좋음.

## 3. 시작 방법

1. 대시보드 접속해서 `'Workers & Pages'` 선택함.
2. 저장소 연결하거나 소스 파일 직접 업로드함.
3. 프레임워크 (React, Next.js 등) 설정하고 배포 버튼 누름.
4. `*.pages.dev` 주소로 사이트 바로 생성됨.
