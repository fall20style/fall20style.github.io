## Python 3.14.3 venv 구축 및 fastmcp 패키지 설치
- Ubuntu 20.04

파이썬 버전을 활성화하고, 독립된 가상환경을 만들어 필요한 라이브러리를 설치하는 표준적인 흐름임.

```
pyenv shell 3.14.3
```
* 의미: 현재 터미널 세션에서 사용할 파이썬 버전을 3.14.3으로 일시 전환함.
* 설명: 이 명령 이후 실행되는 모든 python 명령어는 pyenv가 관리하는 3.14.3 버전을 가리키게 됨.

```
python --version
```
* 의미: 현재 적용된 파이썬 버전을 확인함.
* 목적: 이전 단계에서 설정한 3.14.3 버전이 제대로 활성화되었는지 검증하는 단계임.

```
python -m venv my-env-3.14.3
```

* 의미: my-env-3.14.3이라는 이름의 가상환경 폴더를 생성함.
* 설명: 파이썬 3.14.3 기반의 독립된 공간이 만들어지며, 시스템 전체 환경과 분리된 라이브러리 저장소가 생성됨.

```
cd my-env-3.14.3
```

* 의미: 방금 생성한 가상환경 폴더 안으로 이동함.
* 참고: 가상환경을 켜기 위한 실행 스크립트(bin/activate)가 이 폴더 안에 위치하기 때문임.

```
. bin/activate
```

* 의미: 가상환경을 활성화(Activate)함. (source bin/activate와 동일)
* 효과: 터미널 프롬프트 앞에 (my-env-3.14.3) 표시가 생기며, 이제부터 설치하는 모든 패키지는 이 환경 안에만 저장됨.

```
pip install fastmcp
```

* 의미: 활성화된 가상환경 내부에 fastmcp 패키지를 설치함.
* 장점: 다른 프로젝트의 라이브러리들과 충돌 없이, 오직 이 가상환경 내에서만 fastmcp 도구를 사용할 수 있게 됨.
