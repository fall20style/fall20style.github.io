PM2를 사용하여 Node.js/TypeScript 봇을 관리하고 자동 실행하는 방법 정리임.

## 설치 및 초기 설정

* 설치: npm install -g pm2 (전역 설치 필수임)
* 버전 확인: pm2 -v

## 봇 실행하기

* 일반 실행: pm2 start dist/index.js --name "my-bot"
* TS 직접 실행: pm2 start src/index.ts --name "my-bot" --interpreter ./node_modules/.bin/ts-node
* 파일 변경 시 자동 재시작: --watch 옵션 추가함

## 상태 모니터링

* 리스트 확인: pm2 list (실행 중인 프로세스 상태 확인임)
* 실시간 로그: pm2 logs "my-bot" (에러 디버깅 시 필수임)
* 상세 정보: pm2 show "my-bot"
* 대시보드: pm2 monit (터미널에서 CPU/메모리 모니터링함)

## 프로세스 제어

* 중지: pm2 stop "my-bot"
* 재시작: pm2 restart "my-bot"
* 삭제: pm2 delete "my-bot" (리스트에서 아예 제거함)

## 재부팅 자동 실행 (가장 중요함)

   1. 현재 상태 보존: pm2 save (현재 실행 중인 리스트를 덤프 파일로 저장함)
   2. 부팅 스크립트 생성: pm2 startup
   3. 명령어 실행: 위 명령 결과로 나오는 sudo env PATH... 한 줄을 복사해서 터미널에 입력함
   4. 확인: 서버 재부팅 후 pm2 list로 봇이 떠 있는지 확인함.
