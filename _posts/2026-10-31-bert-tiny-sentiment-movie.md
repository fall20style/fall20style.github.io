## 16GB CPU 환경에서 구축한 완전 오프라인 '재귀적 자기개선(Recursive Self-Improvement)' 데이터 합성 루프

- 오프라인 환경에서 작동하는 한국어 리워드 모델(Reward Model) 구축 및 에이전트 선순환 진화 루프 삽질기

---

### 💡 연구의 핵심 컨셉: 왜 '리워드 모델'인가?

- 오픈소스 진영의 초소형 생성 모델(예: DeepSeek-R1 1.5B 등)은 내 노트북에서도 부드럽게 돌아가지만, 가끔 영어를 뱉거나 어색한 번역체, 혹은 일하기 싫다는 식의 저품질 문장을 출력하는 고질적인 한계.

- 문장의 논리성과 품질을 채점하는 **독립형 한국어 리워드 모델(Reward Model / Critic)**을 직접 훈련
- 생성 모델이 문장을 뱉으면, 내 리워드 모델이 실시간으로 검수하여 점수가 0.85점 이상인 데이터만 하드디스크에 자동 저장하는 필터링 파이프라인을 구축

---

### 🛠️ 16GB CPU 노트북의 한계를 뚫기 위한 하드웨어 최적화 과정

- 475MB 체급의 대형 한국어 사전학습 BERT 모델을 CPU로만 학습시키는 것은 무리
- 처음에는 연산 속도가 이터레이션당 1분(`59.76s/it`)이 찍히며 완료까지 20시간 이상이 찍히는 연산 병목(Throbbing) 현상이 발생
- 노트북 메인보드가 과열되어 터지는 것을 막기 위해 극단적인 연산 다이어트(Compression) 전략

1. **데이터 골디락스 존 찾기**: 무조건 많은 데이터 대신, 2,000개의 알짜배기 정제 샘플로 타협하여 일반화 성능과 속도의 균형을 맞췄습니다.
2. **행렬 차원 압축**: 문장 최대 패딩 길이를 128토큰으로 제한하여 행렬 연산 복잡도를 물리적으로 제한했습니다.
3. **가상 배치 스케일링**: 배치 사이즈를 16으로 확장하여 전체 가중치 업데이트 빈도를 375스텝으로 촘촘하게 조율했습니다.

그 결과, CPU 가속만으로 **약 1시간 57분 만에 안정적인 수렴(`Loss: 0.72 -> 0.17`)을 달성**하며 무사히 3에포크 학습을 완주했습니다!

### 대조 실험 결과

- 파인튜닝 전후 가중치 변화에 따른 모델의 실제 보상 점수(Reward Score: 0.0 ~ 1.0) 분포 차이

| 테스트 입력 문장 | 학습 안 된 베이스 모델 점수 | 2,000샘플 스케일업 완주 모델 점수 | 최종 시스템 판정 결과 |
| :--- | :---: | :---: | :---: |
| *"이 영화는 연출과 스토리가 매우 탄탄해서 깊은 감동을 줍니다."* | `0.4413` | **`0.9988`** | **🔥 고품질 (자기개선 데이터 채택)** |
| *"코드의 가독성을 높이기 위해 리팩토링을 완료했고 완벽하게 작동합니다."* | `0.4604` | **`0.9898`** | **🔥 고품질 (자기개선 데이터 채택)** |
| *"대충 돌아가니까 이대로 빌드하고 제출해 버려야겠습니다."* | `0.4473` | **`0.0025`** | **❌ 저품질 (필터링 자동 탈락)** |
| *"배우들 연기도 어색하고 돈 아까운 최악의 지루한 영화였습니다."* | `0.3530` | **`0.0012`** | **❌ 저품질 (필터링 자동 탈락)** |

#### 주요 관전 포인트 및 해석
- 선명한 양극단 격리: 학습 전에는 반반 찍기(`0.3~0.4`) 수준이던 모델이, 파인튜닝 후에는 우수 문장에 0.99점 고득점을 주고 저품질 문장은 0.001점대 소수점 셋째 자리까지 격리.
- 일반화(Generalization) 성능: 영화 리뷰 톤으로만 학습된 모델, 데이터셋에 존재하지 않던 개발자 전용 도메인 문장(*"코드의 가독성을 높이기 위해 리팩토링을 완료했고..."*)의 논리 구조와 건설적인 뉘앙스를 정확히 전이 학습(Transfer Learning) 0.9898 정밀 점수를 리턴

### 🤖 실전 자동화 가동: 에어갭(Air-gapped) 환경에서의 데이터 합성

- 백그라운드에 로컬 LLM 커널인 `Ollama(DeepSeek-R1)`를 띄우고 실시간 결합 파이프라인(`agent_self_improvement.py`)을 구동
- 외부 인터넷 연결을 차단한 채 노트북 혼자서 연산하는 플로우

```text
Ollama (DeepSeek-R1) 한글 초안 대량 생성 
       ▼
생각 태그(<think>) 파이썬 문자열 엔진으로 자동 분리 제거
       ▼
내가 만든 한국어 BERT 채점관 실시간 평가 
       ▼
[0.85점 이상] 통과작만 golden_self_improvement_dataset.jsonl 에 자동 축적!
```

- 에이전트가 영어 답변을 뱉거나 어색한 한글을 출력하면 리워드 모델이 점수를 0.42대로 깎아버리며 자동 폐기
- 논리적이고 깔끔한 한글 문장만 선별해 골드 데이터셋에 영구 적재

```text
[3/5] 로컬 LLM 에이전트('deepseek-r1:1.5b')에 텍스트 생성 요청 중...
 ├─ 에이전트 답변: 이 기업에 있어서, 엔지니어의 경험을 통해 연산 속도를 대폭 개선해 gave, 기업의 성과를 통해 기업의 성과를 개선하는 데 기대력이 강한 엔지니어의 경험담.
 ├─ 리워드 점수: 0.9933
 └─ 최종 판정: 🔥 합격 (골드 데이터셋 저장)
```
