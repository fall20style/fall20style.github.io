# 뉴스 제목 한 줄로 주제를 맞히는 모델

## 왜 만들었나

뉴스 제목은 짧습니다. 평균 27자, 길어도 44자입니다. 그런데 그 안에 이미 "이 기사가 어떤 분야인지"가 거의 다 들어 있습니다.

> "삼성전자, 3분기 영업이익 10조 돌파" → 경제
> "손흥민, 결승골로 시즌 10호 골" → 스포츠

사람은 이걸 0.1초 만에 판단합니다. 그렇다면 모델도 할 수 있지 않을까? 뉴스 제목 4만 5천 건을 **7개 주제로 분류하는 모델**을 만들어 봤습니다.

## 무엇을 만들었나

| 항목 | 내용 |
|---|---|
| 입력 | 뉴스 제목 문자열 |
| 출력 | 주제 1개 + 주제별 확률 7개 |
| 주제 | IT과학, 경제, 사회, 생활문화, 세계, 스포츠, 정치 |
| 베이스 모델 | Laya `multilingual` (mmBERT-base 322M) |
| 학습 데이터 | 45,654행 |
| 테스트 데이터 | 9,131행 (정답 없음) |

## 어떻게 접근했나

가장 흔한 방법은 인코더 위에 `Linear(768 → 7)` 층을 붙이는 것입니다. 이번에는 Laya의 **choice 질문** 방식을 썼습니다.

``` text
[CLS] choice question: Classify the news headline ... [SEP]

[MASK] IT과학 [MASK] 경제 [MASK] 사회 ... [SEP]

삼성전자, 3분기 영업이익 10조 돌파 [SEP]
```

보기마다 `[MASK]`를 하나씩 붙이고, 그 위치의 벡터를 작은 scorer에 넣어 점수를 냅니다. 보기가 7개니까 점수도 7개, 이걸 softmax로 확률로 바꿉니다.

이 방식의 장점은 **한 번의 forward pass로 모든 보기를 채점**하고, 주제가 늘어나도 `topic_dict.csv`만 고치면 된다는 점입니다.

## 결과

먼저 파이프라인이 도는지 확인하려고 작게 돌렸습니다.

- 데이터: 클래스별 200행, 총 1,400행
- 학습: 2 epoch, encoder 고정, 80번 업데이트
- 검증: 140행

| 지표 | 값 |
|---|---:|
| 검증 정확도 | 53.6% |
| macro F1 | 51.6% |
| temperature | 1.05 |

주제별로는 `스포츠`(F1 0.81), `IT과학`(0.72)이 잘 맞았고, `사회`(0.31), `생활문화`(0.33), `세계`(0.34)는 약했습니다. 테스트 500행 예측에서도 `사회`와 `생활문화`를 학습 데이터 비율에 비해 훨씬 적게 예측하는 편향이 보였습니다.

## 솔직한 한계

이 숫자는 모델의 한계라기보다 **실험 설정의 한계**입니다.

1. 전체 데이터의 3%만 사용
2. 인코더를 고정하고 head만 학습
3. 2 epoch = 80번 업데이트

다음 단계는 명확합니다. 전체 데이터, 인코더까지 파인튜닝, epoch 확대, 그리고 검증셋을 키워 숫자를 믿을 수 있게 만드는 것.

## 배운 것

- **작은 데이터로도 파이프라인은 돈다.** 성능은 데이터 크기와 설정이 결정한다.
- **accuracy만 보면 안 된다.** 클래스별 F1과 혼동 행렬을 같이 봐야 "무엇을 못 맞히는지"가 보인다.
- **확률은 보정이 필요하다.** temperature scaling은 정확도를 바꾸지 않지만 confidence를 믿을 만하게 만든다.
- **체크포인트는 자족적으로.** 추론 코드와 토크나이저까지 같이 저장해 두면 나중에 원본 모델 없이도 재현할 수 있다.
