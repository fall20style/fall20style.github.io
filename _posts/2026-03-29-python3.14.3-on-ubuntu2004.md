
# Ubuntu 20.04에서 python 3.14.3 설치

## Ubuntu에서 `ModuleNotFoundError: No module named '_tkinter'` 해결 방법

`pyenv`로 파이썬을 설치할 때 Ubuntu 시스템에 **Tcl/Tk 개발 헤더**가 없어서 발생함. 빌드 과정에서 이 라이브러리를 찾지 못하면 `tkinter` 모듈 생성을 건너뛰기 때문임.

### 1. Ubuntu 필수 패키지 설치터미널에서 아래 명령어를 실행하여 `tk-dev` 라이브러리를 설치함.

```bash
sudo apt update
sudo apt install tk-dev
```


### 2. 파이썬 재설치 (필수)
패키지 설치 후, 기존에 잘못 빌드된 파이썬을 삭제하고 다시 설치해야 함. 그래야 빌드 시점에 tk-dev 라이브러리를 인식함.

### 설치하려는 버전에 맞춰 수정 (예: 3.14.3)
```
pyenv uninstall 3.14.3
pyenv install 3.14.3
```


### 3. 설치 확인
설치 완료 후 아래 명령어로 tkinter가 정상 작동하는지 확인함. 작은 GUI 창이 뜨면 성공임.

```
pyenv shell 3.14.3
python -m tkinter
```


### 전체 빌드 환경 구축을 다시 한다면?

```
sudo apt install build-essential libssl-dev zlib1g-dev \
libbz2-dev libreadline-dev libsqlite3-dev curl git \
libncursesw5-dev xz-utils tk-dev libxml2-dev \
libxmlsec1-dev libffi-dev liblzma-dev
```

재설치 명령어
```
pyenv uninstall 3.14.3 && pyenv install 3.14.3
```
