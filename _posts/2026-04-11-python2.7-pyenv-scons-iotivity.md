최신 운영체제인 Ubuntu 22.04(Jammy Jellyfish) 쓰면서도 **IoTivity** 같은 레거시 프로젝트나 특정 라이브러리 때문에 Python 2.7 환경이랑 SCons 빌드 도구 필요한 경우 있음. 근데 Ubuntu 22.04는 Python 2.7 공식 패키지 지원 안 해서 설치하기 어려움.

Docker랑 `pyenv` 써서 Ubuntu 22.04 기반에 **IoTivity** 빌드 최적화된 Python 2.7.18 환경 깔끔하게 만드는 `Dockerfile` 분석해봄.

---

### 1. Dockerfile 분석

이 Dockerfile은 IoTivity 빌드에 필요한 의존성 패키지랑 Python 2.7 환경 자동으로 세팅해줌.

```dockerfile
FROM ubuntu:22.04
ENV DEBIAN_FRONTEND=noninteractive

# 1. 필수 의존성 패키지 설치 (IoTivity 및 Python 빌드용)
RUN apt-get update && apt-get install -y \
    sudo scons git make build-essential libssl-dev zlib1g-dev \
    libbz2-dev libreadline-dev libsqlite3-dev wget curl llvm \
    libncurses5-dev libncursesw5-dev xz-utils tk-dev libffi-dev \
    liblzma-dev libglib2.0-dev libboost-thread-dev libboost-system-dev \
    libboost-dev libcurl4-openssl-dev \    
    && rm -rf /var/lib/apt/lists/*

# 2. 사용자 계정 설정 (mjpark)
RUN useradd -m -s /bin/bash mjpark && \
    echo "mjpark ALL=(ALL) NOPASSWD:ALL" >> /etc/sudoers

USER mjpark
WORKDIR /home/mjpark

# 3. pyenv 설치 (파이썬 버전 관리 도구)
RUN curl https://pyenv.run | bash

# 4. 환경 변수 및 bashrc 설정
ENV PYENV_ROOT="/home/mjpark/.pyenv"
ENV PATH="$PYENV_ROOT/bin:$PYENV_ROOT/shims:$PATH"

RUN echo 'export PYENV_ROOT="$HOME/.pyenv"' >> ~/.bashrc && \
    echo '[[ -d $PYENV_ROOT/bin ]] && export PATH="$PYENV_ROOT/bin:$PATH"' >> ~/.bashrc && \
    echo 'eval "$(pyenv init -)"' >> ~/.bashrc

# 5. Python 2.7.18 설치 및 기본값 설정
RUN /bin/bash -c "eval \"\$(pyenv init -)\" && pyenv install 2.7.18 && pyenv global 2.7.18"

CMD ["/bin/bash"]
```

---

### 2. 주요 포인트 정리

#### IoTivity 빌드를 위한 밑작업
*   **Base Image**: Ubuntu 22.04 LTS 써서 보안이랑 안정성 챙김.
*   **Dependencies**: `scons`, `boost`, `libcurl`, `glib` 등 IoTivity 빌드 필수 라이브러리 다 때려넣음. Python 소스 빌드용 패키지도 다 포함됨.

#### 왜 pyenv?
Ubuntu 22.04는 기본 파이썬이 3.10임. 시스템 파이썬 강제로 2.7로 바꾸면 OS 맛탱이 갈 수 있음. `pyenv` 쓰면 사용자 계정 안에서만 Python 2.7 안전하게 쓸 수 있고, `pyenv global 2.7.18` 설정하면 컨테이너 어디서든 `python` 명령어로 2.7 바로 호출 가능해서 편함.

#### 사용자 환경 설정
`root` 대신 `mjpark` 계정 만들어서 보안 높임. `sudo` 권한도 줘서 필요한 패키지 바로바로 깔 수 있게 구성함.

---

### 3. 세 줄 요약

1. IoTivity 같은 레거시 프로젝트는 최신 OS에서 빌드 환경 잡기 어려워 Docker를 사용.
2. 시스템 파이썬 건드리지 말고 `pyenv`로 Python 2.7 깔끔하게 격리해서 쓰는 게 나음.
3. 이렇게 빌드 환경 미리 만들어두면 OS 상관없이 어디서든 삽질 안 하고 빌드 가능함.
