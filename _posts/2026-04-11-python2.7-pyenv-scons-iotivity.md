최신 운영체제인 Ubuntu 22.04(Jammy Jellyfish)를 사용하면서도, **IoTivity**와 같은 레거시 프로젝트나 특정 라이브러리 때문에 Python 2.7 환경과 SCons 빌드 도구가 필요한 경우가 있습니다. 하지만 Ubuntu 22.04에서는 더 이상 Python 2.7을 공식 패키지로 지원하지 않아 설치가 매우 까다롭습니다.

오늘은 Docker와 `pyenv`를 활용해 Ubuntu 22.04 기반에서 **IoTivity** 빌드에 최적화된 Python 2.7.18 환경을 깔끔하게 구축하는 `Dockerfile`을 분석해 보겠습니다.

---

### 1. Dockerfile 분석

이 Dockerfile은 IoTivity 빌드에 필요한 의존성 패키지와 Python 2.7 환경을 자동으로 설정해 줍니다.

```dockerfile
FROM ubuntu:22.04
ENV DEBIAN_FRONTEND=noninteractive

# 1. 필수 의존성 패키지 설치 (IoTivity 및 Python 빌드용)
RUN apt-get update && apt-get install -y \
    sudo scons git make build-essential libssl-dev zlib1g-dev \
    libbz2-dev libreadline-dev libsqlite3-dev wget curl llvm \
    libncurses5-dev libncursesw5-dev xz-utils tk-dev libffi-dev \
    liblzma-dev libglib2.0-dev libboost-thread-dev libboost-system-dev \
    libboost-dev libcurl4-openssl-dev \    
    && rm -rf /var/lib/apt/lists/*

# 2. 사용자 계정 설정 (mjpark)
RUN useradd -m -s /bin/bash mjpark && \
    echo "mjpark ALL=(ALL) NOPASSWD:ALL" >> /etc/sudoers

USER mjpark
WORKDIR /home/mjpark

# 3. pyenv 설치 (파이썬 버전 관리 도구)
RUN curl https://pyenv.run | bash

# 4. 환경 변수 및 bashrc 설정
ENV PYENV_ROOT="/home/mjpark/.pyenv"
ENV PATH="$PYENV_ROOT/bin:$PYENV_ROOT/shims:$PATH"

RUN echo 'export PYENV_ROOT="$HOME/.pyenv"' >> ~/.bashrc && \
    echo '[[ -d $PYENV_ROOT/bin ]] && export PATH="$PYENV_ROOT/bin:$PATH"' >> ~/.bashrc && \
    echo 'eval "$(pyenv init -)"' >> ~/.bashrc

# 5. Python 2.7.18 설치 및 기본값 설정
RUN /bin/bash -c "eval \"\$(pyenv init -)\" && pyenv install 2.7.18 && pyenv global 2.7.18"

CMD ["/bin/bash"]
```

---

### 2. 주요 포인트 정리

#### IoTivity 빌드를 위한 완벽한 밑거름
*   **Base Image**: Ubuntu 22.04 LTS를 사용하여 보안과 안정성을 챙겼습니다.
*   **Dependencies**: `scons`, `boost`, `libcurl`, `glib` 등 IoTivity 빌드에 필수적인 라이브러리들이 모두 포함되어 있습니다. 특히 Python을 소스에서 직접 빌드하기 위한 패키지들도 함께 설치됩니다.

#### 왜 pyenv인가?
Ubuntu 22.04는 기본 파이썬이 3.10입니다. 시스템 파이썬을 강제로 2.7로 바꾸면 OS 전체가 꼬일 수 있습니다. `pyenv`를 사용하면 사용자 계정 내에서만 Python 2.7을 안전하게 사용할 수 있으며, `pyenv global 2.7.18` 설정을 통해 컨테이너 내 어디서든 `python` 명령어로 2.7 버전을 바로 호출할 수 있습니다.

#### 사용자 친화적인 환경 설정
`root` 권한 대신 `mjpark` 계정을 생성하여 보안을 높였고, `sudo` 권한을 부여해 필요 시 패키지를 추가 설치하기 용이하게 구성되었습니다.

---

### 3. 마치며

IoTivity와 같이 Python 2.7과 특정 버전의 SCons에 의존성이 높은 프로젝트를 최신 리눅스 환경에서 다루기란 쉽지 않습니다. 하지만 위와 같이 Docker 환경을 미리 구축해 두면, OS 환경에 구애받지 않고 언제 어디서든 일관된 빌드 환경을 유지할 수 있습니다.
